# EscapeRoomAI - Voice Voting

A static voting website for the team to listen to and rank AI agent voice samples generated by ElevenLabs.

## Live Site

**https://gh05tlab.github.io/EscapeRoomAI/**

Share this link privately with team members.

## How It Works

1. **Enter your name** and press Enter
2. **Listen** to all 11 voice samples using the play buttons or by clicking anywhere on the seek slider
3. **Pick your 1st, 2nd, and 3rd choice** from the voices
4. **Submit** your vote and see aggregated results

### Results Screen

- **Rankings** show weighted scores (1st = 3 pts, 2nd = 2 pts, 3rd = 1 pt)
- **Voter filter tags** let you select specific people to see how subgroups voted
- **Individual votes** show each person's picks in detail

### Admin Controls (bottom of results page)

- **Vote Again** -- clears your local vote so you can re-vote
- **Clear All Votes** -- wipes all votes from the server (confirmation required)

## Tech Stack

- **Single `index.html`** -- no build step, no frameworks
- **GitHub Pages** -- static hosting from `main` branch
- **kvdb.io** -- free CORS-friendly key-value store for vote persistence (no backend needed)
- **localStorage** -- duplicate vote prevention per browser

## Development

No build tools needed. Edit `index.html` and push to `main`. GitHub Pages deploys automatically.

To test locally, open `index.html` in a browser (audio playback requires serving via HTTP -- use `npx serve .` or similar).
